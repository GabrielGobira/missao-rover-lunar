## Rover.py

Script simples que simula a inicialização dos sistemas de um rover.

### Funcionalidade

A função `inicializar_rover()` exibe no console o status inicial do rover:
- Confirmação de que os sistemas foram iniciados
- Status dos painéis solares
- Nível da bateria

### Como executar

```bash
python rover.py
```

### Saída esperada

```
Sistemas do Rover iniciados!
Painéis solares: OK
Nível de bateria: 100%
```
